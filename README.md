# 투두리스트 + 캘린더

HTML / CSS / JavaScript로 만든 로그인 · 일정 관리 웹 페이지입니다.

## 실행 방법
`index.html`을 브라우저로 열면 됩니다. (서버 불필요)

## 기능
- **로그인 / 회원가입** (localStorage 저장)
- **일정 추가**: 할 일 · 시작일 · 마감일 입력, 추가일 자동 기록
- **일정 수정 / 삭제 / 완료 체크**
- **월간 캘린더**: 기간 일정을 막대로 표시, 날짜 클릭 시 해당 날짜 일정 보기
- **마감 상태 표시**: 오늘 마감(주황), D-1·기한 지남(빨강), 완료(초록)
- 전체 / 진행중 / 완료 필터, 사용자별 일정 분리 저장

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html`, `auth.js` | 로그인 / 회원가입 화면 |
| `todo.html`, `todo.js` | 투두리스트 + 캘린더 화면 |
| `style.css` | 공통 스타일 |
